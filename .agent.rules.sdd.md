# Cerne — Regras do Agente (SDD Constitution)

## Identidade do projeto
**Cerne** é um board de tarefas pessoal (Kanban) completamente independente de SaaS. Custo zero.

## Stack de tecnologia
| Camada | Tecnologia |
|---|---|
| Frontend | PWA vanilla (HTML + CSS + JS — sem frameworks) |
| Armazenamento | `data/tasks.json` versionado no GitHub |
| Sincronização | GitHub Contents API (token `repo`) — direto do browser |
| Notas | `notes/*.md` — Markdown livre com front-matter |
| MCP Server | Node.js ESM (`mcp-server/index.mjs`) — `@modelcontextprotocol/sdk` |
| Lembretes | GitHub Actions cron + Gmail SMTP + Telegram Bot API |
| Integrações | Obsidian vault (espelho), Notion API oficial (mirror) |
| Hosting | GitHub Pages ou Vercel (pasta `web/`) |

## Schema de tarefa (fonte da verdade)
```
id, titulo, descricao, coluna (todo|fazendo|revisao|feito),
prioridade (baixa|media|alta), etiqueta (string),
tags[], prazo (ISO date|null), lembrete (ISO datetime|null),
assignees[], notaVinculada, notificadoEm,
criadoEm, atualizadoEm, concluido
```

## Regras de arquitetura
1. **Sem banco de dados** — `data/tasks.json` é a única fonte de verdade.
2. **Sem bundler** — o PWA é HTML+CSS+JS puro servido estaticamente.
3. **Sem dependências no frontend** — zero `node_modules` na pasta `web/`.
4. **MCP server = Node.js ESM** — qualquer nova ferramenta MCP vai em `mcp-server/index.mjs`, adicionando entrada em `TOOLS[]` e handler no `setRequestHandler`.
5. **Scripts de CI** em `scripts/` rodam no GitHub Actions (Node 20). `nodemailer` é a única dependência permitida.
6. **Segredos nunca no repo** — `.mcp.json` está no `.gitignore`. Tokens do GitHub ficam somente no `localStorage` do dispositivo.
7. **Funções pequenas** — máximo 20 linhas por função, máximo 500 linhas por arquivo.
8. **TypeScript não é usado** — JS puro. Se adicionado no futuro, usar JSDoc estrito.
9. **Commits atômicos** — um commit = uma mudança lógica. Mensagens no formato `cerne: <o que fez>`.

## Regras de qualidade visual (web/)
- Design dark-first com variáveis CSS HSL ricas (`--bg`, `--card`, `--blue`, etc.)
- Animações via `cubic-bezier(.22,.61,.36,1)` e `cubic-bezier(.34,1.56,.64,1)` (spring)
- Hover: `transform: translateY(-3px)` em cards, escala em botões primários
- Responsivo: breakpoint em `1000px` (mobile-first no grid principal)
- Fonte: Inter (Google Fonts)

## O que NÃO fazer
- Não editar `data/tasks.json` manualmente a não ser que o Senhor peça explicitamente.
- Não adicionar frameworks JS (React, Vue, etc.) sem aprovação explícita.
- Não introduzir novos arquivos de config de bundler.
- Não expor segredos no código.
